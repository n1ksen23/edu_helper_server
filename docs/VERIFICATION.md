Flutter-тесты проверяют выбор группы, основные разделы, ошибки с повтором, права на кнопки, создание/редактирование ДЗ, вход редактора и secure storage, возврат назад, текст 180% на экране 360 px и сохранение выбора архива при минутном обновлении. Это widget-тесты, а не подтверждение запуска APK на Android-устройстве. Аппаратная клавиатура, системные insets и Android runtime требуют дополнительной проверки на телефоне.

В браузере вручную проверены выбор 4992, текущие задания, недельное расписание, окна, календарь и настройки. После замечания пользователя интерфейс переработан по исходнику: шрифты SF, синяя карточка дня, крупная дата, watermark группы, компактные сегменты, оформление списков, трёхкнопочная нижняя панель. Настройки открываются шестерёнкой. Технические и учебные пояснения в пользовательском UI убраны. Скриншот: docs/home-web.png.

Backend развернут через Git в /opt/eduhelper. PostgreSQL не доступен снаружи, FastAPI слушает loopback через Docker, Nginx принимает HTTPS. Сертификат Let's Encrypt выдан до 20 января 2027, автоматическое продление включено. Smoke-тест по внешнему HTTPS подтвердил health, оба входа, чтение сырого расписания, создание и удаление временного ДЗ. Тестовая запись удалена. Тесты PostgreSQL работали в отдельной eduhelper_test, не в рабочей базе.

В рабочей БД: 7 исходных ДЗ, 6 шаблонов, 108 датированных дней. Исходные 20 строк расписания, преподаватели, аудитории и обе недели сохранены. Импорт запущен повторно и отдельно проверен на идемпотентность; он не перезаписывает последующие правки. Начальная публикация расписания ограничена 18 неделями от 19.10.2026; дальнейшее повторение делает редактор.

Ограничения: нет Telegram/FCM уведомлений, offline-кэша данных и фоновой синхронизации. Нет индивидуальных редакторских аккаунтов (по ТЗ). У подгрупп нет ученического фильтра (по явному правилу ТЗ); разделение ДЗ описывается текстом. Никакая Desktop-платформа не заявляется проверенной. Rate limiter рассчитан на один API worker; для нескольких нужен общий Redis. Production-секреты и ключ подписи находятся вне репозиториев, в C:/Users/nikse/.eduhelper-private/.
