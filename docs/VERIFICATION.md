# Обновление 1.0.4 · 23 октября 2026

Android: Настройки → «Обновление приложения». Проверка версии при запуске и вручную, скачивание внутри приложения с прогрессом и отменой, повтор после ошибки, установка через системный установщик. Разрешение установки запрашивается только после нажатия «Установить»; после возврата из настроек открывается установка. Данные и токены не удаляются. Web не показывает Android-обновления.

Манифест /downloads/android.json: version, build_number, apk_url, sha256, size, notes. Только HTTPS и собственный домен, проверка размера/SHA-256, packageName, versionCode и совпадения подписей установленного и нового APK. Старые версии и другой сертификат отклоняются. Неполные файлы не устанавливаются.

Первый переход с 1.0.3: установить APK 1.0.4 по ссылке. Последующие версии публикуются через tools/publish_android.py: APK и контрольная сумма сначала, манифест атомарно последним. Номер версии и сборки читается из самого APK. Повторная публикация изменённого APK под прежним номером запрещена.

Проверки: 24 теста Flutter; 2 Android/JVM-теста с проверками повреждённого/обрезанного файла, чужого пакета, подписи, понижения и несовпадения номера сборки; flutter analyze без замечаний.

Ограничение проверки: системный установщик и выдача разрешения не запускались на физическом Android-устройстве в этой среде.

# Обновление 1.0.3 · 23 октября 2026

Тип недели рассчитывается автоматически от недели, содержащей 1 сентября соответствующего учебного года: первая — верхняя, затем недели чередуются по понедельникам. Проверки границ сентября и января, воскресенья 1 сентября, удаления настроек из формы администратора.

Отдельная веб-панель удалена 23 октября 2026; `/admin` и `/admin/` возвращают 410. Управление доступно только в приложении; административное API сохранено.

# Обновление 1.0.1 · 22 октября 2026
